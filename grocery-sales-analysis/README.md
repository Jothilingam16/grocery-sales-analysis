**Project Overview**

This project analyzes grocery store sales data to identify sales trends, product performance, customer behavior, and payment preferences using Excel and MySQL.


**Business Objective:**

* Understand overall sales performance
* Identify top-selling products and categories
* Analyze monthly revenue trends
* Study customer demographics and payment modes



**Dataset Description:**

The dataset contains 300+ grocery sales records with the following fields:



* Order\_ID
* Order\_Date
* Customer\_ID
* Customer\_Gender
* Customer\_Age
* Product\_Category
* Product\_Name
* Quantity
* Unit\_Price
* Total\_Amount
* Payment\_Mode
* Store\_Location



**Data Cleaning (Excel):**

* Removed duplicate Order IDs,
* Handled missing customer age values using average age,
* Ensured Total\_Amount = Quantity × Unit\_Price,
* Standardized date format,
* Normalized payment modes (Cash, UPI, Card).



**SQL Analysis Performed:**



* Total revenue calculation
* Sales by product category
* Top-selling products
* Monthly sales trends
* Payment mode distribution
* Customer age group analysis
* City-wise sales performance



**Business Recommendations:**



* Increase inventory for top-selling categories
* Promote digital payment offers
* Run targeted offers for high-value customer groups
* Optimize stock planning based on monthly trends



**Conclusion:**



This project demonstrates my ability to clean data, perform SQL analysis, and derive actionable business insights using Excel and MySQL.
